# EcoShell-AeroLab

## Aerodynamic Analysis & Data Science Toolkit for Shell Eco-marathon

🚧 **Status: In development**

EcoShell-AeroLab is a long-term engineering project focused on
aerodynamic analysis, experimental data processing and performance
optimization of a Shell Eco-marathon vehicle.

The project combines:

- aerodynamic theory,
- experimental data analysis,
- statistics,
- mathematical modelling,
- optimization,
- machine learning.

## Goals

- Analyze wind tunnel data
- Calculate aerodynamic coefficients
- Study vehicle aerodynamic performance
- Develop optimization tools
- Explore machine learning for vehicle performance
- Build a reusable engineering toolkit

- Python
- Git
- GitHub
- RStudio
- Visual Studio Code
